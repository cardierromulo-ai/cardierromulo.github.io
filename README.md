# Rómulo Cardier — Portafolio

Sitio estático listo para GitHub Pages.

## Estructura
- `index.html` — página principal (landing + portafolio, bilingüe ES/EN).
- `assets/` — imágenes de proyectos (comprimidas a ~800KB–1MB c/u).
- `projects/` — páginas web y artefactos IA (HTML autónomos) + PDFs de identidad de marca, enlazados desde las tarjetas.
- `_ds/`, `support.js` — runtime del sistema de diseño, no modificar.

## Publicar en GitHub Pages
1. Sube esta carpeta como raíz del repositorio (o a `/docs` y configura Pages en esa carpeta).
2. En Settings → Pages, selecciona la rama y carpeta donde quedó `index.html`.
3. Listo — la URL del sitio abrirá `index.html` automáticamente.
